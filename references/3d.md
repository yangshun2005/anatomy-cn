# 3D：绘图中可转动的部件

可选的 3D 模式（“转动组”）让图形的某些部件作为刚体运动：旋转的刻度盘或转盘、弯曲的手指、断裂并翻滚的碎片。这些部件每一帧都由工具包自身的规则重新投影和重新着色，并按照由分离平面求解出的顺序绘制。其余部分保持普通的静态工具包图形。未启用该模式的图形不受影响。

**状态：beta。** 该引擎已在 `examples/turning-dial` 和一个测试图形（仅依据本文档构建的台式风扇）上得到验证，尚未在生产图形上验证。一次只转动一个主体，保持杂物静止，并在添加部件之前按照第 15 节衡量你的图形。

## 1. 图形何时值得使用 3D

只有当运动本身就是解释时：一个刻度盘，其数字在转动时被读取；一个转盘，从各个侧面展示物体；一个轮组；一只抓握或断裂的手。绝不作为装饰。只需要部件滑动或指针摆动的图形保持 2D：`translateAlong` 加上重绘的指针更便宜且精确。

## 2. 模型

- **组。** 组是一个带姿态的刚性坐标系。种类：`turn`（绕穿过 `pivot` 的垂直轴，任意角度）、`slide`（沿一个方向，`0…travel`）、`hinge`（绕穿过某点的任意轴，在 `range` 内，以度为单位）和 `free`（任意旋转加平移，由图形每帧设置）。组可以嵌套：姿态相对于父组。
- **静止。** 每个构造函数都接受**静止时的世界坐标**（每个组值为 0，每个自由组为 `null`）。引擎减去每个组的原点，因此记录器（`A.recorder`）、工具包和引擎共享同一个世界。
- **实时图层。** 实时图层是舞台中的一个 `<svg class="iso-svg iso-live" data-live="name">`。实时图层和静态图层按照 `T.stack([...])` 的顺序堆叠：例如 `back svg → [dial live] → back canvas → [hand live] → front canvas → front svg`。
- **恒等式。** 将组绕垂直轴转动 θ 恰好等于工具包在方位角 `a − θ` 处绘制，因为工具包的光照是相机锁定的。因此转动组的每一帧都是工具包在 P′(θ) 处的自身图像，只是发生了平移；P′(θ) 处的工具包构建器是保真度参考，每个工具包屏幕空间审计在 P′(θ) 处原样运行。铰链和自由组则组合矩阵（正确，稍慢）。

## 3. 最小页面

`examples/turning-dial/` 是参考场景：一个带滚花、刻度和数字的刻度盘，第二个转动组（窗口下的索引轮），一个铰链（骑在滚花上的棘爪），一只约 80 个部件带材质的手，一根抬起的三铰链手指，一个作为自由组断裂的六角舱，以及一个 WebGL LED、光池和火花。`examples/turning-dial/stress.mjs` 是性能场景（凌乱工作台上转盘中的密集手部）；它并非审计干净，因此请从 `build.mjs` 中借鉴模式。

`build.mjs`，缩减为其骨架：
```js
import * as k from "../../kit/iso-kit.mjs";
import * as A from "../../kit/audit.mjs";
import { turning } from "../../kit/turn-build.mjs";
import * as TA from "../../kit/turn-audit.mjs";
import { turnScript, glScript } from "../../scripts/inline-kit.mjs";

export const P = k.fitProjection(points, W, H, { pad: 22, azimuth: 40, elevation: 31 });
export const R = A.recorder(P);
export const T = turning(P, { recorder: R });
const dial = T.group("dial", { turn: { pivot: [0, 0] } });
const lift = T.group("f2.mcp", { parent: dial, hinge: { point: C1, axis: w, range: [-22, 0] } });
const hand = T.layer("hand");
T.stack(["back", "hand", "front"]);
export const follow = (values) => ({ ...values, "f2.mcp": -22 * (values.lift ?? 0) });
export const poses = () => Array.from({ length: 720 }, (_, i) => follow({ dial: i * 0.5, lift: (i % 90) / 90 }));

T.round({ name: "dial.body", group: dial, layer: hand, F: VERT(0, 0), s0: 10, s1: 14.4, r: 50, material: "steel", details: { ribs: { s0: 10.9, s1: 13.7, count: 150, seams: true, tone: "lo" } } });
T.prism({ name: "hand.palm", group: dial, layer: hand, plan: PALM, z: 19.4, h: 8, bevel: 0.9, material: "gold" });
T.tube({ name: "cable.red", group: dial, layer: hand, route, r: 0.7, hue: "red", material: "rubber", gaps });
// … static kit art: R.put({ name, layer: "back", svg, shapes }) as usual …

const out = T.build({ statics: R.items, poses, verify: argv.includes("--verify") });
A.settle(R, P);
if (argv.includes("--audit")) {
  A.auditOrExit(R, P);
  TA.orbitOrExit(T, R, P, { sweep: { at: (x) => follow({ dial: x }), from: 0, to: 360, frame: 0.3 }, clips: [{ name: "tap", at: (t) => follow({ dial: 40 + 12 * t, lift: tapAt(t) }), from: 0, to: 4, frame: 1 / 60 }] });
}
const stage = `<div class="iso-stage iso-turn" tabindex="0" role="slider" …>${backSvg}${out.layerSvg("hand", { width: W, height: H })}${frontSvg}</div>`;
const page = k.pageHtml({ title, theme, body: k.plateHtml({ …, body: `<style>${out.css}</style>${stage}` }), script: turnScript() + LIVE });
```
`live.js`：
```js
const controller = TURN.mount(stage, DATA.turn, { follow, onHold: () => (touring = false), onFrame: () => paint() });
function tick(now) {
  …
  controller.set({ dial: angle, lift });
  frame = visible && moving ? requestAnimationFrame(tick) : 0;
}
```
图形拥有循环（`motion.md`）；控制器从不运行自己的 `requestAnimationFrame`。`out.css` 是 `TURN_CSS`（面带规则、材质、色相管和 `.iso-turn` 堆叠）：包含一次即可。

**在 React 或 Next.js 中**（`references/react.md`）：将 `turn.mjs`、`turn-build.mjs` 和 `turn-audit.mjs` 复制到工具包旁边，并重写导入（`./iso-kit.mjs` → `./kit`，等等），并将 `TURN_CSS` 作为 `turn.css` 导入一次。几何模块（服务端）运行 `turning(…)` 和 `T.build(…)` 并返回舞台标记（每个实时图层的 `out.layerSvg(name, { width, height })`，按堆叠顺序位于静态 SVG 和画布之间）以及图形数据中的 `out.data`。客户端挂载调用 `TURN.mount(stageElement, data.turn, { follow, onHold, onFrame })` 并从自己的循环驱动 `controller.set(...)`；从 effect 的清理函数中返回 `controller.destroy`。验证构建可以将 `out.verify` 放入数据中，并让挂载为 `turn-check --order` 赋值 `window.__isoVerify`。

## 4. 创作 API

### 场景
| 调用 | 作用 |
|---|---|
| `turning(P, { recorder, scale = 1 })` | 构建器 `T`。传入工具包记录器，以便每个实时形状也被记录用于工具包审计。 |
| `T.group(name, { parent?, turn: { pivot: [x, y] } })` | 绕穿过 `pivot` 的垂直轴旋转，值以度为单位。 |
| `T.group(name, { parent?, slide: { direction, travel } })` | 平移，值 `0…travel` 世界单位。 |
| `T.group(name, { parent?, hinge: { point, axis, range: [lo, hi] } })` | 绕穿过 `point` 的 `axis` 旋转，值在 `range` 内以度为单位。 |
| `T.group(name, { parent?, free: { origin } })` | 自由刚体（第 7 节）。值为 `{ R: [9] \| q: [x, y, z, w] \| axis, angle, t: [3], world? }` 或静止时为 `null`。 |
| `T.layer(name)`、`T.stack([…])` | 实时图层以及实时和静态图层名称的完整堆叠，从后到前。 |
| `T.build({ statics, poses, verify = false, strict = true })` | 求解每一对，证明每个静态项的图层，打包页面数据。`poses` 是图形的可达状态（列表或返回列表的函数）：每个运动片段，采样。对任何没有分离平面的对、任何无法证明的静态项、任何非凸部件抛出可读错误。`strict: false` 保留互锁对（以便植入的故障到达审计）。 |

`T.build` 返回 `out = { svg, data, css, report, layerSvg(name, { width, height }), verify }`。`out.data` 传给页面（`DATA.turn`）。`out.report` 包含 `parts`、`layers`（每层：`planar`、`framed`、`dynamic`、`skip` 计数）、`tight`、`margins`、`proofs`、`seconds`。

### 构造函数
每个构造函数的通用选项：`{ name, group, layer, tone = "hi", crease = "faint", lit = false, material, owner, details = {} }`。

| 构造函数 | 部件 |
|---|---|
| `T.prism({ plan, z, h, steps, bevel })` | 竖直的工具包板（工具包 `extrude` 规则）。 |
| `T.prism({ F, polygon, s0, s1, round = 0, steps = 4, bevel = 0 })` | 坐标系 `F = { o, a, u, v }` 中的凸多边形，沿 `F.a` 从 `s0` 挤出到 `s1`，任意轴（`prismOf` 规则）。 |
| `T.round({ F, s0, s1, r \| [r0, r1], ends = ["flat", "flat"], fixed })` | 圆柱或圆锥台；每端为 `"flat"`、`"dome"`（半径必须等于侧面的：胶囊）或 `"open"`。一个圆顶加一个平端是半胶囊，任意长度都可行，甚至短于半径（电机罐上的鼻锥）。直立组中的竖直圆自动成为 `fixed` 图片（`fixed: false` 阻止它）。 |
| `T.lathe({ F, profile, slope, radius })` | 一般凸光滑体（r(s) 凹）。昂贵；优先使用圆。 |
| `T.ball({ c, r, flats: [{ n, d }] })` | 球体；每个平面保持 n·(p − c) ≤ d 并将其边缘绘制为帽，因此 `n` 是平面的外法线。没有平面时它是 `fixed` 图片，且不接受 `details`。它是最昂贵的绘制种类（第 15 节）。 |
| `T.tube({ route, r, chunk = 6, turn = 20, gaps, breaks, caps, rings, hue, material, bundle, owner, touch })` | 工具包 `tubePieces` 语义，分块；`hue` 为 `"red" \| "green" \| "blue"`；记录 `R.route`。路径从安装面到安装面。每端的端口、密封套或夹具是单独部件，`owner` 设为管的名称，其沿路径的跨度放入 `gaps`。从端口外表面开始的路径在工具包审计中 `terminals` 失败（见下文）。 |
| `T.fixed({ svg, anchor, shapes, hull, F })` | 任何在组运动下图像不变的 kit 标记，通过 `translate` 移动。 |
| `T.plane({ part, o, u, v, svg, fade = [0.04, 0.3], normal })` | 部件平面中的线条或文本标记（刻度、数字、标签板），由一个矩阵放置，按朝向淡出。 |
| `T.billboard({ part, at, normal, svg, fade })` | 投影点处屏幕对齐的标记（着色器发光的 SVG 回退），按朝向淡出。`svg` 以 viewBox 像素为单位居中于投影点，而非世界单位：将世界尺寸乘以 `G.scaleOf(P)`（`<circle r="${(1.1 * G.scaleOf(P)).toFixed(2)}"/>` 填充半径 1.1 的透镜）。 |
| `T.split(part, { n, d })` | 由平面切割的两个部件（棱柱：沿轴或横跨轴的任意平面；圆：横跨）。切割边缘不描边。用它来打破真正的循环。 |

### 细节（在部件的坐标系中：`s` 沿轴，`x` 和 `y` 在 `u` 和 `v` 中）
每个构造函数有自己的坐标系并接受自己的细节种类。其他任何内容都被忽略且不发出警告。

| 构造函数 | 坐标系 `[s, x, y]` | 接受 |
|---|---|---|
| `T.round`、`T.lathe` | `F`：`s` 沿 `F.a`，`x` 沿 `F.u`，`y` 沿 `F.v` | `seams`、`ribs`、`bolts`、`dots`、`rings`、`rules` |
| `T.prism({ F, polygon })` | `F` | `dots`、`seams`、`bevel` |
| `T.prism({ plan, z, h })` | 世界：`s` 是 z，`x` 和 `y` 是世界 x 和 y | `dots`、`seams`（z 值）、`bevel` |
| 带平面的 `T.ball` | 原点 `c`，`a` = 第一个平面的 `n`，`u` 和 `v` 来自 `G.frameAlong(c, n)`。平面在 `s = d`，远极在 `s = −r` | `bolts`、`dots`、`rings`、`rules` |
| 不带平面的 `T.ball` | 无：固定图片 | 无 |
| `T.fixed({ F })` | `F`（无 `F`：无细节） | `bolts`、`dots`、`rings`、`rules` |

圆顶旋转器 `T.ball({ c, r: 4.5, flats: [{ n: [-1, 0, 0], d: 0 }] })`（平面朝 −x，圆顶朝 +x）上的中心点位于 `at: [-4.5, 0, 0], normal: [1, 0, 0]`：`s = −r` 是极点。`[4.5, 0, 0]` 会落在平面后方 4.5 处，进入旋转器所安装的任何物体内部。对于棱柱面上的环或规则，使用 `T.plane`。
```js
details: {
  seams: [s…],                                              // rings on rounds, ring seams on prisms
  ribs: { s0, s1, count, phase, twist, fade: [0.1, 0.55], seams: true, tone },   // knurl rows on rounds
  bolts: [{ s, r, count, phase, size: 0.5, tone: "mid", fade: [0.04, 0.42] }],   // bolt circles
  dots: [{ at: [s, x, y], normal, size, tone }],
  rings: [{ at: [s, x, y], normal, r, tone }],              // become planes
  rules: [{ points: [[s, x, y]…], tone, free }],            // become planes
  bevel: 0.4…1.6,                                           // prism cap bevel (faded slots)
}
```
每个细节都随朝向淡出：点和螺栓按 `smoothstep(0.04, 0.42, n·V)`，肋逐肋，斜面线逐边，平面按组的透明度。没有纹理在满强度处停止。
